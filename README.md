# do-you-still-love-me

A fun collection of interactive Java programs that ask love questions! 💕

## Programs

### 1. LoveMessageGenerator.java
A random love message generator that displays 10 random romantic, playful, and poetic responses.

**Usage:**
```bash
javac LoveMessageGenerator.java
java LoveMessageGenerator
```

**Features:**
- 💕 Romantic responses
- 😉 Playful/funny responses  
- ✨ Poetic responses
- 🎲 Random mix of all three

---

### 2. DoYouLoveMe.java
An interactive program that responds to "Do you love me?" with different reactions based on your choice.

**Usage:**
```bash
javac DoYouLoveMe.java
java DoYouLoveMe
```

**Features:**
- 💕 **YES** - Heartfelt confirmations
- 😢 **NO** - Playful "gotcha" moments that turn into yes!
- 🤔 **MAYBE** - Sweet responses leading to yes!
- 🎲 **RANDOM** - Surprise mix of all responses
- 👋 **EXIT** - Say goodbye

Each response is randomized, so you get different answers every time!

---

## Requirements
- Java 8 or higher
